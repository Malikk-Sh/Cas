# CAS — сканер криптоарбитража

CAS ищет потенциальные spot-связки по публичным стаканам без API-ключей и без автоматического выставления ордеров.

## Режимы

### 1. Межбиржевой арбитраж

Для заданной пары бот сравнивает несколько бирж, моделирует покупку по ask-стакану и продажу по bid-стакану, считает VWAP, примерные taker-комиссии и дополнительный запас на издержки.

### 2. Треугольный арбитраж внутри одной биржи

Бот автоматически строит доступные трёхшаговые циклы из spot-маркетов выбранной биржи, например:

```text
USDT → BNB → ETH → USDT
```

Для каждой ноги он определяет правильную сторону рынка:

- если нужно перейти из quote в base — моделирует BUY по asks;
- если нужно перейти из base в quote — моделирует SELL по bids.

После каждой ноги из полученного количества вычитается taker-комиссия. Затем применяется дополнительный safety haircut (`CAS_FIXED_COST_BPS`). Связка отбрасывается, если глубины хотя бы одного стакана не хватает на заданный объём.

## Что умеет

- публичные стаканы через CCXT;
- Bybit, OKX, KuCoin и другие spot-биржи, поддерживаемые CCXT;
- VWAP по нескольким уровням стакана;
- межбиржевые и треугольные связки;
- автоматический перебор треугольных маршрутов;
- общий taker fee и отдельные fee-overrides по биржам;
- фильтр по минимальной net-доходности;
- Telegram-уведомления с деталями каждой ноги;
- Docker, unit-тесты и GitHub Actions.

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -e ".[dev]"
cp .env.example .env
cas-scanner
```

Или через Docker:

```bash
docker build -t cas-scanner .
docker run --rm --env-file .env cas-scanner
```

## Основные настройки

- `CAS_EXCHANGES` — биржи через запятую;
- `CAS_SYMBOLS` — пары для межбиржевого режима;
- `CAS_NOTIONAL_USDT` — стартовый объём проверки;
- `CAS_DEPTH_LIMIT` — глубина стакана;
- `CAS_MIN_NET_PROFIT_PCT` — порог межбиржевого алерта;
- `CAS_TRIANGULAR_MIN_NET_PROFIT_PCT` — порог треугольного алерта;
- `CAS_TAKER_FEE_BPS` — комиссия по умолчанию, в basis points;
- `CAS_EXCHANGE_TAKER_FEE_BPS` — overrides, например `bybit:10,okx:8,kucoin:10`;
- `CAS_FIXED_COST_BPS` — дополнительный консервативный запас;
- `CAS_TELEGRAM_BOT_TOKEN` и `CAS_TELEGRAM_CHAT_ID` — Telegram.

### Настройка треугольного перебора

`CAS_TRIANGULAR_ANCHOR_ASSET=USDT` задаёт актив, в котором начинается и заканчивается цикл.

`CAS_TRIANGULAR_ASSETS=BTC,ETH,BNB,SOL,XRP,ADA,DOGE` задаёт universe промежуточных монет. Конкретные маршруты вручную перечислять не нужно: бот сам найдёт все существующие треугольники внутри этого universe.

Чтобы разрешить все активные spot-активы биржи, можно указать:

```env
CAS_TRIANGULAR_ASSETS=*
```

Это может резко увеличить число стаканов и привести к rate-limit, поэтому `CAS_TRIANGULAR_MAX_CYCLES` ограничивает число проверяемых циклов.

## Как считается треугольная связка

Пусть старт — `1000 USDT`, а маршрут — `USDT → BNB → ETH → USDT`.

1. По `BNB/USDT` бот покупает BNB по asks на 1000 USDT.
2. По `ETH/BNB` покупает ETH за полученные BNB.
3. По `ETH/USDT` продаёт ETH по bids обратно в USDT.
4. После каждой ноги учитывает taker fee.
5. Сравнивает итоговый USDT со стартом и применяет safety haircut.

Алерт отправляется только если net-процент выше заданного порога.

## Ограничения

Это сканер, а не торговый робот. Он не резервирует ликвидность и не гарантирует, что три сделки удастся исполнить по тем же ценам. Реальная комиссия зависит от VIP-уровня, скидок, способа списания fee и конкретной биржи. При ручной торговле дополнительно учитывай минимальные размеры ордеров, precision, остатки после округления и изменение стакана между ногами.

Для межбиржевого режима также важны заранее распределённые балансы, состояние сетей ввода/вывода и комиссии перевода.

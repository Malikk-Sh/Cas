# CAS — сканер криптоарбитража

MVP-сканер ищет межбиржевые spot-возможности по стаканам: где купить актив дешевле и продать дороже с учетом глубины рынка, примерной taker-комиссии и дополнительного запаса на издержки.

## Что уже умеет

- получает публичные стаканы через CCXT;
- сравнивает Bybit, OKX, KuCoin или другие CCXT-биржи;
- считает VWAP по реальной глубине стакана на заданный объем;
- оценивает gross/net прибыль после комиссий;
- фильтрует связки по минимальному net-проценту;
- отправляет уведомления в Telegram;
- работает без API-ключей, потому что сделки не исполняет;
- содержит unit-тесты и GitHub Actions.

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -e ".[dev]"
cp .env.example .env
cas-scanner
```

Или через Docker:

```bash
docker build -t cas-scanner .
docker run --rm --env-file .env cas-scanner
```

## Настройка

Основные переменные находятся в `.env.example`.

- `CAS_EXCHANGES` — список бирж через запятую;
- `CAS_SYMBOLS` — пары, например `BTC/USDT,ETH/USDT`;
- `CAS_NOTIONAL_USDT` — размер тестируемого объема;
- `CAS_MIN_NET_PROFIT_PCT` — минимальная расчетная доходность для алерта;
- `CAS_TAKER_FEE_BPS` — приблизительная комиссия одной сделки в basis points;
- `CAS_FIXED_COST_BPS` — дополнительный запас на проскальзывание/операционные расходы;
- `CAS_TELEGRAM_BOT_TOKEN` и `CAS_TELEGRAM_CHAT_ID` — Telegram-уведомления.

## Важное ограничение

Это сканер, а не торговый робот. Межбиржевой арбитраж обычно требует заранее распределенных средств на нескольких биржах. Перевод монет между биржами может занять время, сеть может быть временно закрыта, а комиссии и ликвидность могут измениться до исполнения сделки. Любую найденную связку нужно повторно проверять непосредственно перед торговлей.

## Следующий этап

# CAS — сканер криптоарбитража

CAS ищет потенциальные spot-связки по публичным стаканам и, при необходимости, по котировкам внешних обменников. Бот не выставляет ордера и не отправляет средства автоматически.

## Режимы

### 1. Межбиржевой арбитраж

Для заданной пары бот сравнивает несколько бирж, моделирует покупку по ask-стакану и продажу по bid-стакану, считает VWAP, примерные taker-комиссии и дополнительный запас на издержки.

### 2. Треугольный арбитраж внутри одной биржи

Бот автоматически строит доступные трёхшаговые циклы из spot-маркетов выбранной биржи, например:

```text
USDT → BNB → ETH → USDT
```

Все три операции исполняются внутри одной биржи. Для каждой ноги CAS выбирает BUY/SELL по направлению пары и проверяет реальную глубину стакана.

### 3. Гибридный маршрут через внешний обменник

Этот режим сделан для связок вида:

```text
USDT → BNB (Bybit spot)
BNB → ETH (внешний обменник, например BNB BEP20 → ETH ERC20)
ETH → USDT (Bybit spot)
```

То есть первая и последняя ноги проверяются по реальным CEX-стаканам, а средняя нога берётся из live quote внешнего сервиса.

Для такого режима CAS:

- покупает первый актив по asks с учётом глубины;
- вычитает CEX taker fee;
- запрашивает у внешнего quote-провайдера точный выход для полученного количества;
- оценивает стоимость входа и выхода внешней ноги по ликвидным CEX bid-ценам;
- помечает котировку подозрительной, если она создаёт слишком много стоимости из ничего;
- проверяет, можно ли реально продать весь выходной актив обратно в USDT по доступной глубине;
- вычитает fee последней CEX-сделки и общий safety haircut;
- отправляет Telegram-алерт только для безопасной связки выше заданного порога.

По умолчанию подозрительные котировки не считаются рабочими, даже если математически показывают огромную прибыль.

## Почему нужен sanity-check внешнего обменника

У ликвидных монет вроде BNB и ETH нет экономического механизма, который позволял бы обычному обменнику стабильно отдавать на десятки или сотни процентов больше рыночной стоимости. Если сервис показывает такой результат, это чаще означает ошибку единиц, неправильный токен/сеть, неисполняемую рекламную котировку или риск мошенничества.

Настройка:

```env
CAS_HYBRID_MAX_EXTERNAL_PREMIUM_PCT=5
CAS_HYBRID_ALLOW_SUSPICIOUS=false
```

Если внешняя нога дороже spot-эквивалента более чем на 5%, CAS по умолчанию логирует её как подозрительную и не отправляет как торговый сигнал.

## Внешние quote-провайдеры

CAS не привязан к одному обменнику. Провайдер описывается JSON-конфигурацией в `CAS_EXTERNAL_QUOTE_PROVIDERS_JSON`.

Пример для документированного JSON API:

```env
CAS_EXTERNAL_QUOTE_PROVIDERS_JSON='[{"kind":"http","name":"example","url":"https://example.com/api/quote","method":"GET","params":{"from":"{from_asset}","to":"{to_asset}","amount":"{amount}"},"response_mode":"json","output_path":"data.outputAmount","input_network":"BEP20","output_network":"ERC20"}]'
```

Доступны подстановки:

- `{from_asset}`;
- `{to_asset}`;
- `{amount}`;
- `{input_network}`;
- `{output_network}`.

Для HTML/text-ответа можно использовать `response_mode: "text"` и `output_regex` с первой capture-группой или именованной группой `amount`.

`kind: "static_rate"` существует только для unit-тестов и ручной диагностики. Он не является live-источником и не должен использоваться как торговый сигнал.

## Настройка маршрута со скриншота

Базовая форма маршрута:

```env
CAS_HYBRID_ENABLED=true
CAS_HYBRID_EXCHANGES=bybit
CAS_HYBRID_ANCHOR_ASSET=USDT
CAS_HYBRID_ROUTE_PAIRS=BNB:ETH
CAS_HYBRID_START_AMOUNT_USDT=1000
CAS_HYBRID_MIN_NET_PROFIT_PCT=0.20
```

`BNB:ETH` означает: купить BNB за anchor-актив, передать BNB во внешний quote-провайдер и получить ETH, затем продать ETH обратно в anchor-актив.

Можно перечислить несколько маршрутов:

```env
CAS_HYBRID_ROUTE_PAIRS=BNB:ETH,SOL:ETH,BTC:ETH
```

## P2P/фиатная нога

Связка из поста начинается с покупки USDT за RUB. Текущая версия CAS считает стартом уже полученный объём USDT (`CAS_HYBRID_START_AMOUNT_USDT`). Это сделано намеренно: официальный P2P API Bybit для списка объявлений требует авторизованный P2P API-доступ/ключ рекламодателя. Неофициальный scraping P2P-страницы в core не используется.

Если у пользователя есть официальный P2P API-доступ, отдельный адаптер можно подключить следующим этапом без изменения логики гибридного маршрута. До этого стартовую сумму USDT можно задавать по фактической лучшей P2P/обменной котировке.

## Что умеет

- публичные стаканы через CCXT;
- Bybit, OKX, KuCoin и другие spot-биржи CCXT;
- VWAP по нескольким уровням стакана;
- межбиржевые, треугольные и гибридные маршруты;
- общий taker fee и отдельные fee-overrides по биржам;
- HTTP JSON/text adapters для внешних quote API;
- проверка достаточной ликвидности для входа и выхода;
- sanity-check внешней котировки относительно CEX spot;
- фильтр по минимальной net-доходности;
- Telegram-уведомления;
- Docker, unit-тесты и GitHub Actions.

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -e ".[dev]"
cp .env.example .env
cas-scanner
```

Или через Docker:

```bash
docker build -t cas-scanner .
docker run --rm --env-file .env cas-scanner
```

## Основные настройки

- `CAS_EXCHANGES` — биржи через запятую;
- `CAS_SYMBOLS` — пары для межбиржевого режима;
- `CAS_NOTIONAL_USDT` — стартовый объём межбиржевого/треугольного режима;
- `CAS_DEPTH_LIMIT` — глубина стакана;
- `CAS_MIN_NET_PROFIT_PCT` — порог межбиржевого алерта;
- `CAS_TRIANGULAR_MIN_NET_PROFIT_PCT` — порог треугольного алерта;
- `CAS_HYBRID_MIN_NET_PROFIT_PCT` — порог гибридного алерта;
- `CAS_TAKER_FEE_BPS` — комиссия по умолчанию;
- `CAS_EXCHANGE_TAKER_FEE_BPS` — overrides, например `bybit:10,okx:8,kucoin:10`;
- `CAS_FIXED_COST_BPS` — дополнительный консервативный запас;
- `CAS_TELEGRAM_BOT_TOKEN` и `CAS_TELEGRAM_CHAT_ID` — Telegram.

## Ограничения

CAS пока не исполняет сделки. Он не резервирует ликвидность внешнего обменника, не подтверждает доступность конкретной сети ввода/вывода и не может гарантировать, что котировка сохранится до ручного перевода. Для внешних сервисов дополнительно нужно проверять домен, репутацию, минимальную/максимальную сумму, сеть, комиссию, время жизни quote и адрес назначения.

Автоматическое отправление средств на неизвестные обменники намеренно не реализовано.

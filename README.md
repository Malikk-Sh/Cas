# CAS — Crypto Arbitrage Scanner

Сканер spot-арбитража по публичным стаканам и внешним котировкам. Поддерживает три режима:

- межбиржевой: купить актив дешевле на одной бирже и продать дороже на другой;
- треугольный внутри одной биржи: автоматически ищет циклы вида `USDT → BNB → ETH → USDT`;
- гибридный: например `RUB → USDT` через Bybit P2P, затем `USDT → BNB` на Bybit, `BNB → ETH` во внешнем обменнике и `ETH → USDT` снова на Bybit.

Сканер моделирует исполнение по глубине стакана, учитывает taker-комиссии и safety haircut. Для гибридных маршрутов дополнительно сравнивает внешнюю котировку с CEX spot-ценой и помечает экономически невозможные/подозрительные котировки.

Подробная инструкция на русском: [`docs/README.ru.md`](docs/README.ru.md).

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
cas-scanner
```

Или через Docker:

```bash
docker compose up --build
```

Для межбиржевого и треугольного режимов API-ключи бирж не нужны. Гибридный режим получает внешние котировки через настраиваемые HTTP quote-провайдеры (`CAS_EXTERNAL_QUOTE_PROVIDERS_JSON`).

Опционально CAS может читать официальный список online-объявлений Bybit P2P и использовать фактическое количество USDT, доступное за заданную сумму RUB, как размер следующей ноги. Для этого нужен официальный Bybit P2P API-доступ и ключи в локальном `.env`. Ключи не нужно передавать кому-либо и нельзя коммитить в Git. CAS вызывает только чтение объявлений и не создаёт P2P-заказы.

Сам бот не отправляет монеты во внешние сервисы и не исполняет сделки.

> Важно: найденная связка не гарантирует прибыль. Особенно внимательно проверяйте неизвестные обменники. Если внешний сервис показывает выход, который создаёт несколько процентов стоимости относительно ликвидного spot-рынка, CAS по умолчанию блокирует такую котировку как подозрительную.

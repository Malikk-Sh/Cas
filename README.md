# CAS — Crypto Arbitrage Scanner

Сканер spot-арбитража по публичным стаканам. Поддерживает два режима:

- межбиржевой: купить актив дешевле на одной бирже и продать дороже на другой;
- треугольный внутри одной биржи: автоматически ищет циклы вида `USDT → BNB → ETH → USDT`.

Оба режима считают исполнение по глубине стакана, учитывают taker-комиссии, дополнительный запас на издержки и умеют отправлять Telegram-уведомления.

Подробная инструкция на русском: [`docs/README.ru.md`](docs/README.ru.md).

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
cas-scanner
```

Или через Docker:

```bash
docker compose up --build
```

Сделки бот не исполняет и API-ключи бирж ему не нужны. Для треугольного режима маршрут строится из активных spot-маркетов выбранной биржи, а каждая из трёх ног проверяется по реальному стакану на заданный объём.

> Важно: найденная связка не гарантирует прибыль. К моменту ручного исполнения стакан и комиссии могут измениться. Если на бирже комиссия списывается не из получаемого актива, фактический результат также может отличаться от модели.
